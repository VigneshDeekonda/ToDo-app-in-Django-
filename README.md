# Todo App using Django

A simple and efficient Todo List web application built using the Django framework. This project was created as part of my journey into backend web development and helped me understand the fundamentals of Django, including URL routing, views, templates, forms, and database integration.

## Overview

The Todo App allows users to create, manage, and organize their daily tasks through a clean and user-friendly interface. The project demonstrates how Django can be used to build dynamic web applications with minimal code while following the MVC (Model-View-Template) architecture.

## Features

- Add new tasks
- View all tasks
- Update existing tasks
- Delete completed tasks
- User-friendly interface
- Dynamic data rendering using Django templates
- SQLite database integration

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite3

## What I Learned

Through this project, I gained practical experience with:

- Setting up and configuring Django projects
- Understanding Django's project and app structure
- Working with URL routing and views
- Creating and rendering templates
- Handling user input through forms
- Connecting Django with databases
- Performing CRUD (Create, Read, Update, Delete) operations
